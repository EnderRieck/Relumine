# 联网查证（web-lookup）

当问题需要外部、最新或库内没有的信息时：

1. 用 `web_search` 检索（query 用精炼关键词，必要时多检索几次换关键词）。
2. 从结果中挑 1-3 个最相关、最权威的页面，用 `browse_page`（mode=text）读取正文。
   - 页面是图表/需要视觉确认时可用 mode=screenshot。
3. 综合多个来源后回答，**每条关键结论后用 [n] 标注来源**，并在末尾列出
   `[n] 标题 — URL`。
4. 来源相互矛盾时如实说明分歧；信息不足时明确说"未找到可靠来源"，不要编造。

注意：联网与浏览较慢，按需使用；能用站内字库/文化图谱工具回答的就不要联网。
